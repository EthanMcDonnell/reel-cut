# ReelCut icon directions

ReelCut currently has no standalone identity asset. These are **three original review directions**, inspired by the existing gold-on-charcoal title-card system in `config.yaml`. They are not product output and none is an official logo yet.

A separate image-generation pass was used only to explore the geometry and visual balance before these reviewable SVGs were drawn as clean vector assets. No generated image depicts the application, footage, terminal output, or a real third-party mark.

| Option | File | What it communicates | Trade-off |
| --- | --- | --- | --- |
| **Frame Cut** *(recommended)* | [`frame-cut.svg`](frame-cut.svg) | A 9:16 output frame and one deliberate editorial cut. It reads as a short-form video editor even at favicon size. | Most abstract of the three; does not immediately say “captions.” |
| **Splice** | [`splice.svg`](splice.svg) | Two film segments connected at a splice point. It foregrounds assembly and editing. | More visually detailed at small sizes. |
| **Caption Cursor** | [`caption-cursor.svg`](caption-cursor.svg) | Caption lines and a playhead, which directly nods to ReelCut’s transcript/EDL workflow. | The most product-specific option, but less iconic as a small social avatar. |

If one direction is approved, redraw only that option into final multi-size SVG/PNG exports in a follow-up. Avoid creating a new wordmark; the existing Playfair Display title-card treatment remains ReelCut’s primary typographic identity.
